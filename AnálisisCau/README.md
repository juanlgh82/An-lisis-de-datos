Análisis de incidencias de un CAU
Estado: en desarrollo
Proyecto de análisis de datos de un Centro de Atención a Usuarios (CAU) con Power BI.
Objetivo
Analizar la carga de trabajo y los tiempos de resolución para identificar oportunidades de mejora en el servicio de soporte técnico.
Preguntas del análisis
¿Cómo evoluciona el volumen de incidencias?
¿Qué categorías concentran más solicitudes?
¿Cuál es el tiempo medio de resolución?
¿Cuántas incidencias permanecen pendientes?
¿Se cumplen los plazos de resolución establecidos?
Herramientas previstas
Excel para revisar los datos.
Power Query para limpiarlos y transformarlos.
Power BI y DAX para calcular indicadores y crear el cuadro de mando.
Fuente de datos
Pendiente de incorporar y documentar.
Resultados
Se añadirán las capturas del cuadro de mando, los indicadores y las conclusiones cuando se complete el análisis.
